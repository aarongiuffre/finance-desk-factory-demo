# Staged sudo steps (for Aaron)

Agents on this box run without sudo. Anything that needs root is staged here as a
script that does a dry run by default and changes nothing until it gets `--apply`.

| Script | What it does | Run |
|---|---|---|
| `install_finance_health_system_onfailure.sh` | Adds `OnFailure=finance-health-onfailure@%n.service` drop-ins to the system units finance-quote, finance-refresh, finance-facts and zfs-replicate, plus a system template that runs `scripts/finance_health.py` as slowglow. Nothing is restarted. | `sudo bash ops/staged_sudo/install_finance_health_system_onfailure.sh` (dry run), then `--apply`; `--revert` (dry run) then `--revert --apply` undoes it |
| `install_gate_key.sh` | Pins Aaron's public SSH key in root-owned `/etc/finance-gate/allowed_signers` (namespaces finance-holdout, finance-custody, finance-go). It is the only key fold_gate and encrypt_full_period trust; the repo copy is ignored (Verifier F6). | `sudo bash ops/staged_sudo/install_gate_key.sh aaron.pub` (dry run), then `--apply`; `--revert [--apply]` moves the pin aside |
| `leave_root_equivalent_groups.sh` | Removes slowglow from `docker` and `wheel`, which are root-equivalent. Every other on-box lock depends on this step. | dry run, then `--apply`; `--revert [--apply]` |
| `install_finance_gate_user.sh` | Optional. Moves the two chained logs and their anchors to `/var/lib/finance-gate`, owned by the `finance-gate` user, and adds an append-only sudo helper (Verifier F3/F12). Root-side work goes through `finance_gate_migrate.py` (sha-pinned in the script): no symlink following, ownership checks, copies under the chain flocks, idempotent with no anchor rollback (Verifier v4). v5: chainlog.py and finpaths.py are sha256-pinned too (re-pin when they change); a failed verify-chain removes the sudoers rule as well as the marker; revert reads `/var/lib/finance-gate` through the helper's `read-file`. | dry run (works without sudo), then `--apply`; `--revert [--apply]` |
| `split_research_dataset.sh` | Verifier v5 C-E2. Moves the 2020+ research data (raw/price/h1_universe, folds/validation, raw/dera_*/202[0-6]q*.zip -> raw/research_zips/) onto `fastpool/finance-research/*` with `com.sun:auto-snapshot=false` and `finance:replicate=false`, and patches the sha-pinned `/usr/local/bin/zfs-replicate.sh` to skip such datasets (backup kept). Copies are sha-verified before an original is removed. Must run before `encrypt_full_period.sh` (which refuses otherwise). Destroying the pre-split snapshots of fastpool/ROOT/cachyos and their backuppool replicas is NOT done here: it is Aaron's separate, explicit step (commands in the script header). After the split, a validation copy can no longer be rebuilt by hard links (other dataset); restore it from the archive. | dry run (works without sudo), then `--apply`; `--revert [--apply]` copies everything back and restores the replicate script |

See `ops/edge_threat_model.md` for the order and for what each step closes.
